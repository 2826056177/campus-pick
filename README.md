# 拾机 CampusPick

拾机是一款面向大学新生的校园机会决策助手。它把分散的比赛、讲座、学习小组、项目招募、科研和志愿活动整理成可搜索、可比较、可规划的信息中心，帮助新生从“看到通知”走到“做出行动”。

## 解决的问题

新生面对大量校园信息时，往往不知道哪些适合自己的基础与兴趣，也容易错过截止时间。拾机使用考核题目提供的 18 条模拟校园信息，通过搜索筛选、偏好推荐和个人计划降低选择成本。

## 主要功能

- 按关键词、类型和截止时间发现机会
- 查看原始信息、参与条件和相似通知提示
- 收藏机会，设置“想了解、准备参加、已完成、已放弃”等状态
- 添加个人备注；收藏、状态、备注和偏好刷新后仍会保留
- 通过对话描述兴趣、基础、时间和组队意愿，获得可解释的机会推荐
- 响应式布局，适配桌面与手机浏览器

## AI 顾问说明

当前公开版本默认使用本地规则推荐，因此无需 API Key 也能完整演示。推荐内容严格限定在题目提供的 18 条信息中，并会解释推荐理由。在线大模型接入层会通过服务端代理扩展，API Key 不会写入公开仓库或 GitHub Pages 页面。

## 本地运行

需要 Node.js 20 或更高版本，并推荐使用 pnpm。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 数据边界

所有机会均为考核题目提供的模拟信息。题目没有提供的报名地址、联系人、具体地点等信息均显示为“未说明”，不会擅自补充。编号 01 与 09 的内容高度相似，产品保留两条原始信息并进行相似提示。

## 自主设计

- 将机会发现、判断和行动计划串成完整使用流程
- 为推荐结果提供理由，避免黑盒式排序
- 对相似通知和缺失字段进行明确提示
- 核心功能不依赖后端，适合 GitHub Pages 稳定演示

## 如果继续开发

最希望完善安全的在线 LLM 代理，使 AI 顾问支持更自然的多轮对话；同时增加计划导出、截止提醒和用户自定义机会录入。

## 技术栈

React、TypeScript、Vite、Lucide Icons、浏览器 LocalStorage、GitHub Actions、GitHub Pages。
